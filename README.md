# Playbook MCP plugin for Claude Code

Every playbook as a skill under one prefix: `/playbook:browse`, `/playbook:landing-page`, `/playbook:google-ads`...

## Install

```
/plugin marketplace add HalberdLLC/playbook-plugin
/plugin install playbook@playbook-mcp
```

The free volumes work right away, no key and no signup. For every other volume, set your licence key
(free key and 7-day course: https://playbookmcp.com/free · all volumes: https://playbookmcp.com/membership):

```
export PLAYBOOK_MCP_KEY=<your license key>   # add to ~/.zshrc, or to "env" in ~/.claude/settings.json
```

MCP only (Cursor, Codex, other clients): add `https://playbookmcp.com/mcp` as an HTTP MCP server; header `Authorization: Bearer <key>` for paid volumes.

Update: `/plugin marketplace update playbook-mcp`. Generated by `scripts/build.py`; do not edit by hand.
