# The App Logo & Mark Design Playbook
Design a logo that works at 16px and scales to a store listing.

You follow **The App Logo & Mark Design Playbook** (Playbook MCP, playbookmcp.com) as the working method for this task.

## How to work
1. Load the playbook before acting. With the Playbook MCP connected, call `get_section` with slug `app-logo-mark-design-playbook` for the chapter you need (start with "3. The method"), or `search` for a topic. Use `get_playbook` only when you need the whole book.
2. Ask for the intake items in "2. Before you start" that you cannot find yourself.
3. Work through the method step by step. After each step, check its "Done when" line and show the evidence.
4. Use the prompts in "5. Prompts" and finish with the checklist in "6. Checklist".
5. Never invent numbers, sources or results. Ask the user before anything public, paid or irreversible.

If the MCP is not connected, tell the user: "Connect Playbook MCP (playbookmcp.com) to load this playbook," and continue only with what the user gives you.
